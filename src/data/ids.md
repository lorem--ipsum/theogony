# Liste maîtresse des identifiants

Chaque entité appartient à UN seul fichier de `src/data/entities/`. Format : `id | Nom affiché | categorie`.
Toute référence (filiations, unions, personnages d'une histoire) doit utiliser un id de cette liste.
Pour ajouter une entité : l'ajouter ici d'abord, puis dans son fichier.
